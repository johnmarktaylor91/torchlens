# TorchLens recent methods

Each notebook runs one published method end to end on TorchLens. Some build a small model in
the notebook and run offline; the others download the public models or transcoders named in
their description ("Downloads ...", with the size) from the Hugging Face Hub at a pinned
revision on first run, and still finish in minutes on a laptop CPU.

The six the main README names come first, then the rest by difficulty.

| Recipe | Difficulty | Description |
| --- | --- | --- |
| [`jacobian_lens_recipe.ipynb`](jacobian_lens_recipe.ipynb) | Intermediate | Jacobian lens (Gurnee et al. 2026) on GPT-2 small: keep the live residual stream with `save_mode="view"`, fit one corpus-average Jacobian per block with batched `torch.autograd.grad`, check it against `torch.func.jacrev`, and read it out beside the logit lens with `logit_lens(lens=...)`. Downloads GPT-2 small (about 550 MB). |
| [`jacobian_lens_mamba_colab.ipynb`](jacobian_lens_mamba_colab.ipynb) | Intermediate | The Jacobian lens on Mamba-130m, a state-space model outside the paper reference code's recognized layouts: fit all 23 matrices from `save_mode="view"` traces in about thirty lines of plain PyTorch, read every layer beside the logit lens on four prompts, and check sampled rows against exact scalar autograd. Colab-ready (Run all). Downloads Mamba-130m (about 500 MB); the fit takes several minutes on a two-core CPU. |
| [`logit_lens_recipe.ipynb`](logit_lens_recipe.ipynb) | Beginner | The logit lens (nostalgebraist 2020) on GPT-2 small: `trace.using("mechinterp").logit_lens()` decodes every block's output through the model's own final norm and unembedding, then the same computation with plain PyTorch forward hooks, and a check that the two agree bit for bit. Downloads GPT-2 small (about 550 MB); seconds on a laptop CPU. |
| [`eap_ig_circuit_recipe.ipynb`](eap_ig_circuit_recipe.ipynb) | Intermediate | EAP-IG (Syed, Rager and Conmy 2023; Hanna, Pezzelle and Belinkov 2024) on GPT-2 small's IOI task: `torchlens.mechinterp.edge_scores` ranks every component-graph edge from five gradient evaluations, the name movers of Wang et al. 2022 surface at the top, and `patch_edges` checks the circuit's faithfulness per kept fraction. Downloads GPT-2 small (about 550 MB); a few minutes on a laptop CPU. |
| [`attribution_graph_transcoders_recipe.ipynb`](attribution_graph_transcoders_recipe.ipynb) | Advanced | Attribution graph (Ameisen et al. 2025) on GPT-2 small with the public Dunefsky et al. 2024 transcoders: splice them in as a replacement model, build the graph with `tl.attribution.build_graph`, read what writes the answer logit, ablate the top feature and export for Neuronpedia's viewer. Downloads GPT-2 and the transcoders (about 2.2 GB). |
| [`vision_logit_lens_recipe.ipynb`](vision_logit_lens_recipe.ipynb) | Beginner | The logit lens for vision models (Vilas, Schaumloeffel and Roig 2023; Gandelsman, Efros and Steinhardt 2024): a ViT-tiny classifier's per-block class votes through its own head, and CLIP's open-vocabulary readout of every vision block, both validated against the model's logits. Downloads ViT-tiny and CLIP ViT-B/32 (about 620 MB); under a minute. |
| [`leace_concept_erasure_recipe.ipynb`](leace_concept_erasure_recipe.ipynb) | Intermediate | LEACE concept scrubbing (Belrose et al. 2023): fit the closed-form eraser of subject number at every GPT-2 small block, bind the twelve `tl.when` rules to the model as one live executor, and watch a linear probe fall to chance and subject-verb agreement collapse, while a random direction per block changes nothing; one block alone also breaks agreement although number re-emerges linearly downstream. Downloads GPT-2 small (about 550 MB); about a minute. |
| [`das_causal_basis_recipe.ipynb`](das_causal_basis_recipe.ipynb) | Advanced | Distributed alignment search (Geiger et al. 2024): learn a rotation through a bound hook, then test the causal basis with `tl.subspace` and `tl.patch_from` against a random direction and whole-layer patching. |
| [`contrastive_direction_recipe.ipynb`](contrastive_direction_recipe.ipynb) | Beginner | Representation-engineering (Zou et al. 2023) positive-minus-negative activation direction, added with `tl.steer` at replay. |
| [`probe_accuracy_by_layer_recipe.ipynb`](probe_accuracy_by_layer_recipe.ipynb) | Beginner | Linear probe on every layer of one trace, accuracy plotted against depth with an untrained-network control (Alain and Bengio 2016; Belinkov 2022). |
| [`causal_trace_recipe.ipynb`](causal_trace_recipe.ipynb) | Intermediate | Causal trace (Meng et al. 2022): clean-versus-corrupt activation patching, per-site sweeps with `trace.find_sites`, output-divergence scoring, and `tl.viz.causal_trace_heatmap`. |
| [`measure_faithfulness_recipe.ipynb`](measure_faithfulness_recipe.ipynb) | Intermediate | Output drop, ranked zero-ablation (ROAD-style, without ROAD's imputation step) and a locality check on a toy model, after `tl.validate(scope="intervention")` confirms the baseline forward replays. |
| [`generation_step_iterator_recipe.ipynb`](generation_step_iterator_recipe.ipynb) | Intermediate | A decode loop made explicit, each step traced under its own hook plan, on a tiny local generator. |
| [`train_tuned_lens_recipe.ipynb`](train_tuned_lens_recipe.ipynb) | Intermediate | Train a tuned lens from a disk-mode `tl.extract_dataset` artifact and apply it through `logit_lens(lens=...)`, which checks the recorded model identity. |
| [`clip_head_attention_recipe.ipynb`](clip_head_attention_recipe.ipynb) | Intermediate | Per-head attention maps of CLIP ViT-B/32's vision tower from the `pattern` facet, rebuilt from the fused attention kernel, and which heads send the class token's attention to the object. Downloads `openai/clip-vit-base-patch32` (about 600 MB). |
| [`cka_rsa_two_models_recipe.ipynb`](cka_rsa_two_models_recipe.ipynb) | Intermediate | Layer-by-layer linear CKA and RSA heatmaps between two CNNs of different width and seed, one `tl.neuro.compare` call per column (Kornblith et al. 2019; Kriegeskorte et al. 2008). |
| [`trainable_intervention_recipe.ipynb`](trainable_intervention_recipe.ipynb) | Advanced | Learn an additive vector at one activation site by gradient descent through forked replays, with the model frozen. |
| [`function_vectors_recipe.ipynb`](function_vectors_recipe.ipynb) | Advanced | Function vectors (Todd et al. 2024) on GPT-2 small: score every attention head's causal indirect effect with bound hooks, sum the top heads into a task vector, and add it zero-shot with `tl.steer` to turn country prompts into capitals. Downloads GPT-2 small (about 550 MB). |
| [`clip_text_decomposition_recipe.ipynb`](clip_text_decomposition_recipe.ipynb) | Advanced | Gandelsman et al. (ICLR 2024): split CLIP's image embedding into per-head `result` terms, mean-ablate layers, and name color and shape heads with TextSpan. Downloads `openai/clip-vit-base-patch32` (about 600 MB). |

visualisation, dissection, ACDC, tuned lens, Grad-CAM and more) are in the field guide, [`docs/field-guide/`](../../docs/field-guide/).
