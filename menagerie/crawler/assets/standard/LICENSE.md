# Standard input assets

The files in this directory were created for the TorchLens menagerie crawler and are dedicated to the
public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

- `image.ppm`: an original 8-by-8 RGB color-checker image.
- `text.txt`: an original fixed English model-probe sentence.
- `tabular.csv`: original synthetic tabular values containing no third-party data.
- `audio.csv`: an original short synthetic waveform containing no recording.
