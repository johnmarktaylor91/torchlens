# Review checklist

One page. A change is ready when every line below holds; a reviewer who cannot tick a line
asks for the evidence rather than assuming it.

## Public surface

- [ ] The public surface is unchanged, or the glossary (`docs/reference/glossary.md`), the
      agent reference pages (`docs/agent-reference/`), `examples/` and `notebooks/audit/`
      are updated in the same change. `python tools/name_lockstep check --base ref:<base>`
      exits 0.
- [ ] No new top-level `tl.*` name without a reason; new names live in submodules.
- [ ] A renamed or removed name is removed, not shimmed; no deprecation alias is added.
- [ ] Refusals use a typed error class and a stable code; no caller is expected to match
      message text.

## Validation

- [ ] `torchlens/validation/` is unchanged, or the change strictly consolidates it. No
      tolerance widened, no check skipped, no exemption broadened. A failing validation is a
      capture bug that the change fixes at its root.
- [ ] Any new exemption covers one correct-by-design case, narrowly, and still fails on the
      unintended case.

## Structure

- [ ] No module whose job is to check, witness, ledger, attest or contract another module. A
      correctness concern has one implementation and one behaviour test.
- [ ] No file over 800 lines and no function over 60 unless a comment names the reason; the
      file-cap allowlist only shrinks.
- [ ] A new subsystem is a package whose `__init__` states its seam, not a family of root
      `_x_*.py` modules.
- [ ] A deferred import appears only in a module marked as a facade.
- [ ] A new environment switch is listed in the one module that lists them all.
- [ ] No sprint, memo or work-item id anywhere in code, comments, docstrings, tests or docs.
- [ ] Module names say what they hold.

## Tests

- [ ] The new test is a row in an existing table (behaviour net, corpus, stress axis), or the
      change says why a new function was needed.
- [ ] No test imports a private module outside `tests/internals/`, pins a count, reads the
      package source, patches a private symbol, or asserts only `is not None`.
- [ ] Every test over five seconds carries `heavy` or `slow`; nothing new enters smoke
      without a matching demotion under the size ceiling.
- [ ] The targeted files, the commit gate (`python scripts/smoke_ci_parity.py -n 4`) and,
      for a boundary change, `pytest tests/ -m "not rare and not slow"` are green on a worker,
      with the job ids in the change description.

## Docs and artifacts

- [ ] Every docstring says what the module or function does, never when or in which round it
      was written.
- [ ] Every generated artifact has a regenerate script named in its header, and the artifact
      was regenerated by that script in this change, not edited by hand.
- [ ] `python tools/docs/where_index.py --check` passes after a module is added, moved or
      renamed.
- [ ] No private path, machine name, internal folder or credential reference appears in any
      tracked file.

## Commit

- [ ] Conventional commit type (`feat`, `fix`, `refactor`, `docs`, `test`, `chore`, `perf`,
      `ci`), no `!` marker, no breaking-change footer; breakage is described in plain words.
- [ ] Named-path commits only; the version in `pyproject.toml` and `torchlens/__init__.py`
      is untouched.
