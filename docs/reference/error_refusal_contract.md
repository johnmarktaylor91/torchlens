# Error refusal contract

User-reachable TorchLens refusals are subclasses of `torchlens.errors.TorchLensError` and retain
their historical built-in exception compatibility where applicable. Callers should branch on
`exc.fields["code"]`, never on message text. Each refusal covered by this contract also carries a
non-empty `exc.fields["remedy"]`, and its human-readable message ends with that remedy.

The argument and capture-context classes are resolved lazily from `torchlens.errors`; they do not
add names to the top-level `torchlens` namespace:

- `InvalidArgumentError(ConfigurationError, ValueError)`
- `ArgumentTypeError(ConfigurationError, TypeError)`
- `ArgumentConflictError(ConfigurationError, ValueError)` — VALUE-combination
  conflicts (well-typed options whose values are mutually exclusive, e.g.
  `streaming.bundle_path` + `streaming.out_callback`) were historically raw
  `ValueError`s; the typed refusal preserves that catchability.
- `KeywordConflictError(ConfigurationError, TypeError)` — KEYWORD/call-surface
  conflicts (deprecated kwarg + replacement, grouped option + flat field, two
  exclusive call surfaces) were historically raw `TypeError`s (Python's
  duplicate-keyword convention); the typed refusal preserves that catchability.
  The split is site-by-site per git history, never a blanket base.
- `CaptureContextError(CaptureError, RuntimeError)`
- `DiagnosticSeverityError(ConfigurationError, ValueError)`
- `PayloadUnavailableError(CaptureError, ValueError)`
- `RecordBindingError(CaptureError, RuntimeError)`

Subpackage refusal families resolve lazily from `torchlens.errors` as well, so every
user-reachable class has one public catch spelling. The defining subpackage stays the import home,
and class names marked DOCUMENTED-UNSTABLE by their subpackage keep that status:

- `torchlens.errors.episode`: `BundleExperimentError(ValidationError, RuntimeError)` beside its
  eagerly-imported episode/bundle siblings.
- intervention binding and regions: `BindingPreflightError(ConfigurationError, ValueError)`,
  `BindingRuntimeError(InterventionError, RuntimeError)`,
  `RegionError(ConfigurationError, ValueError)`.
- observability: `ObservabilityError(ConfigurationError)` and its `StatKernelError`,
  `HistorySchemaError`, `HistoryArtifactError`, `WatchPlanError`, `ObserverEventError`,
  `SpanError`, `ProfilerSessionError`, `WatchRenderError` subclasses, plus
  `WatchLifecycleError(CaptureError)`.
- trackers: `TrackersError(ConfigurationError)` and its `SinkProtocolError`, `SinkDeliveryError`,
  `TagGrammarError`, `WatchConfigError` subclasses, plus `WatchRuntimeError(CaptureError)`.
- kit and appliance refusals: `CheckConfigError(ConfigurationError)`,
  `CheckLifecycleError(CaptureError)`, `CheckViolationError(CaptureError)` (checks);
  `ReadError(TorchLensError, ValueError)`, `ReadInternalError(TorchLensError, RuntimeError)`
  (one-backward attribution); `GradFnWalkError(CaptureError)` (debug);
  `ModelExplorerExportError(CaptureError, RuntimeError)`;
  `FeatureShapingError(ConfigurationError, ValueError)`;
  `SiteInventoryError(ConfigurationError, ValueError)`;
  `MechInterpError(TorchLensError, RuntimeError)`;
  `NeuroHandoffError(ConfigurationError, ValueError)`;
  `PreprocessingAuditError(ConfigurationError, RuntimeError)`;
  `NormReconstructionError(TorchLensError, RuntimeError)`;
  `EchoConfigError(ConfigurationError)`, `EchoStatsError(CaptureError)` (snoop);
  `FittedArtifactError(ConfigurationError, RuntimeError)`;
  `TvizError(TorchLensError, RuntimeError)`; `RankRenderEndpointError(GraphvizRenderError)`.
- warning categories: `PluginLoadWarning(TorchLensWarning)` (soft plugin-load failures) and
  `SynthesizedValueReadWarning(TorchLensWarning)` (first raw value read on a trace whose inputs
  were synthesized).

## Stable codes

| Code | Refusal | Remedy class |
|---|---|---|
| `activation_not_saved` | Requested op activation was not retained by `save=` | Re-run the capture with `save=` covering the op |
| `agent_argument_invalid` | An agent-surface tool request violated its declared input schema (missing/unknown key, wrong type, closed-vocabulary miss) | Follow the declared input schema; the refusal names the supported arguments |
| `agent_artifact_kind_unsupported` | An agent tool was pointed at a non-Trace artifact (Bundle, InterventionSpec, ...) | Load non-Trace artifacts in Python via `tl.load(path)` |
| `agent_artifact_load_refused` | Manifest-declared payload entries exceed the single-tool-call load bound | Load it in Python via `tl.load(path, lazy=True)` where the caller controls the budget |
| `agent_artifact_unreadable` | An agent tool path names nothing on disk | Pass the path of an artifact saved with `tl.save(trace, path)` |
| `agent_continuation_drift` | A paging continuation's artifact, request, ordering, or schema changed between pages | Re-issue the query from page one; stale pages refuse, never silently reinterpret |
| `agent_limit_invalid` | A requested budget limit is non-positive or exceeds the served ceiling | Requests lower ceilings, never raise them; run the unbounded spelling in Python |
| `agent_name_unknown` | api_map detail mode named a spelling that is not on the root surface | List the surface with api_map first |
| `agent_query_ceiling` | A query AST tripped the depth/node/string decoder ceilings | Split or shorten the query; ceilings are DoS bounds, not semantics |
| `agent_query_invalid` | A query AST violated the closed v1 grammar, or requested a deliberately-refused kind (regex, callables, value predicates) | Use the supported leaves/combinators; value-dependent selection runs in Python |
| `agent_reduction_invalid` | A payload_stats reduction named a bad dimension or omitted the required ranking metric | Pass an in-range `retain_dim` and a `rank_by` metric when the extent exceeds `max_rows` |
| `agent_schema_unknown` | The schema tool was asked for an unserved schema id | Fetch the index first; the refusal lists every served id |
| `agent_tool_unknown` | An agent tool call named an unregistered tool | Use a served tool name; the refusal lists the roster |

| `trace_forward_kwargs_unrouted` | `tl.trace(model, input_ids=...)`-style model-input keywords are never silently absorbed | Pass them via `input_kwargs={...}`, or use `torchlens.bridge.hf.trace_text` for HF text models |

| `artifact_distributed_scope_invalid` | Loaded `Trace.distributed_scope` is outside the closed `None` / `rank_local_shard` vocabulary | Re-save the source trace; do not invent distributed-scope markers |

## Constant-spelled refusal kinds

These refusals identify themselves on `exc.fields["kind"]` (one
entry per structured finding) rather than `exc.fields["code"]`, and their identifier
strings are spelled as module-level constants rather than inline `code="..."`
literals. They are part of the same stable public vocabulary: branch on the kind
string, never on message text. The lockstep gate enrolls each constant explicitly
(`tests/test_error_contract_lockstep.py`), so renaming the constant or drifting its
string value fails the gate exactly like an inline code.
