# Warning contract (S-18)

TorchLens warnings that steer user decisions carry a stable machine-readable
`code` in `warning.fields["code"]` and a structured remedy in
`warning.fields["remedy"]` (derived at the one `TorchLensWarning` chokepoint
from the authored `Remedy: ...` message tail, exactly like the error base).
Consumers branch on `fields["code"]`, never on message text.

This table is the closed vocabulary of CONTRACTED warning codes. The
alias-resolving warn-site census and the lockstep gates live in
`tests/composition_expectations/` (S-18): every `code=` passed at a
`warnings.warn` construction site must have a row here, every row here must
resolve to a live warn site, and the uncoded-site count is a monotone
ratchet burning down to zero. A warning attached to a wrong or unusable
result is a GAP, not a disclosure (compo memo D3); silently overriding an
explicit user request is a typed conflict, never a warning.

| Code | Warning | Remedy class |
|---|---|---|
| `annotation_sweep_sites_skipped` | A default `*_evolution` sweep skipped saved sites that are not stimulus-indexed (buffer overwrites, leading-axis mismatches); processing them would fabricate stimulus-space results (neuro memo D4/D5) | Select stimulus-indexed sites explicitly; an explicit `save=` selection of a skipped site raises the full teaching refusal |
| `extraction_position_ids_derived` | `extract_dataset` derived `position_ids` from a non-right-aligned attention mask and passed them to the model's forward; derived positions match single-sequence forwards exactly for absolute-position models and change nothing for rotary models (extract memo D5, disclosed once per run) | Right-pad the batch (`padding_side="right"`) or include explicit `position_ids` in each batch to silence the derivation |
| `batchnorm_train_stats_mutated` | Tracing ran the model's real forward and train-mode norm layers with `track_running_stats=True` advanced their running statistics in place (momentum applies even inside `torch.no_grad` / `inference_only=True`); fires once per process | `model.eval()` before observational captures, or snapshot `state_dict()` to roll statistics back; training-through-trace users ignore |
| `failed_capture_release_incomplete` | After a FAILED capture TorchLens could not fully remove its instrumentation from the model (a secondary release failure); the model may keep instance-level forward wrappers and fail to pickle | Call `tl.release_model(model)` once the underlying condition is resolved |
| `module_filter_zero_saved` | The `module_filter` third save gate suppressed every payload the save selection picked: the returned trace carries full metadata but zero saved activations (the natural nn.Module-shaped filter matches nothing because the predicate receives an op-record namespace) | Write the filter against op-record fields (e.g. `lambda op: op.func_name == 'linear'`), or drop `module_filter` |
| `stop_after_never_fired_callable` | A callable or ambient (`tl.experimental.stop_after` context manager) stop-after site never fired: the capture ran the full forward and the outputs are the model's real outputs, not a frontier (selector-shaped explicit sites REFUSE typed instead: `stop_after_never_fired`) | Check the stop_after site against the executed model, or drop stop_after |
| `recipes_unknown_provider` | `activate_entrypoint_recipes(names=...)` was asked for entry-point names that are not installed; the unknown names were skipped and every installed provider name is listed (disclosed, never silent) | Activate an installed provider name from `installed_recipe_providers()`, or install the provider distribution first |
| `legacy_constructor_uncaptured` | `wrap_torch` left a legacy tensor constructor (`torch.<dtype>Tensor`, `torch.autograd.Variable`) unpatched because another tool's Python-level `__new__` is in effect on it (or one was set and removed and its C constructor cannot be recovered): calls to it during capture are not logged, so `tl.validate` may report unowned dispatches; TorchLens never clobbers foreign patches. Fires once per class per process; the class is listed by `torchlens.backends.torch.legacy_ctors.skipped_legacy_constructor_classes()` | Remove the other tool's `__new__` patch before the first capture (in a fresh process if it was already applied and removed) |
| `rerun_zero_fire` | A rerun hook plan entry fired at zero sites on the new inputs; the rerun completed but those interventions were silent no-ops (the flagship silent-wrongness signal) | Resolve the target sites against the rerun trace (`trace.resolve_sites`) before re-applying, or route the edit through the push engine (`fork().do(...)`), which validates sites at plan time |
| `runnable_random_init_run` | A weight-free runnable artifact (the default `include_weights=False`) is executing on RANDOM `torchlens_role_init_v2` state: outputs come from a freshly initialized model, not the captured one, and the report's `verified` attests path faithfulness against that random state (WT1 A-IV item 17, A08) | Re-save with `tl.save(trace, path, level='runnable', include_weights=True)`, or bind real weights with `trace.load_state_dict(state_dict)` before `run()` |
| `episode_pass_window_occurrence_axis` | A cross-pass window (`stable_across_passes` / `pass_variance`) resolved on an EPISODE capture: pass indices are per-site occurrence counters (pass k of a layer = the k-th time THAT layer ran), never episode steps — a layer absent from a step has no pass there, so pass k need not lie at episode step k (foldB D11 read disclosure; payload carries `episode_steps` and per-layer `site_passes`; the typed refusal waits for the explicit step axis at F-EPISODE) | Window by per-site occurrence deliberately, mapping occurrences to steps through `trace.annotations['episode']['rows']`; an explicit step axis is a named future surface, not a selector argument today |
| `dense_subspace_full_axis_edit` | `do()` received a subspace selection whose basis supports the ENTIRE bound axis: under the documented set semantics the edit rewrites every element of the axis, never the component along the direction (list-A row 8 point-of-use disclosure; the projection-valued edit is a named fork, not a shipped capability) | Use a sparse direction (or raise `tol=`) to target a subset, or accept the full-axis edit knowingly |
| `bundle_relation_unknown_kinds_opaque` | `tl.load` found member-relation rows of unknown NAMESPACED kinds; they loaded OPAQUE — preserved verbatim for re-save, never executed, unchecked where a grade applies (the C07X preserve-and-disclose loader doctrine, leg (a)) | Load with the provider that registers these kinds, or pass `tl.load(..., unknown_relations='refuse')` for the strict refusal |
| `sweep_baseline_absent` | `tl.sweep` built a bundle with NO pristine baseline member (legacy cardinality): every member is intervened, so baseline-anchored reads (`most_changed`, `output_delta`, ...) will refuse `BaselineUndeterminedError` — disclosed at CONSTRUCTION, not at first comparison (F03 ledger memo item 2) | Pass `include_baseline=True` to mint one un-intervened `'baseline'` capture first, or `bundle.add` a pristine member later |
| `ledger_torn_tail_discarded` | An experiment-ledger artifact carried one torn TAIL line (an interrupted final write, e.g. a kill -9 mid-event); it was discarded and every finalized event recovered (F03 item 10: kill -9 after event k recovers exactly k events) | None needed — the disclosure IS the record; interior breaks refuse instead |
| `ledger_entry_quarantined` | An experiment-ledger write failed AFTER material work: the entry is QUARANTINED (its rows stop being claims) and the material result is returned unharmed with `material_action_completed=True` (F03 D4g, the adjudicated quarantine default) | Fix the sink (disk/permissions) and open a new entry; arm with `on_record_error='raise'` for strict audit contexts |
| `bundle_unknown_sections_preserved` | `tl.load` found unknown NAMESPACED top-level `bundle.json` sections; they loaded OPAQUE — preserved through the Bundle carriage and re-emitted verbatim on save, never executed (the C07X preserve-and-disclose loader doctrine, leg (c)) | Load with the provider that owns the sections to consume them, or ignore this disclosure |
| `node_overlay_partial_match` | A `node_overlay` mapping matched only SOME of its requested keys on the drawn trace; painted nodes reflect only the realized rows (leverage B8: partial joins disclose, legends derive from realized rows) | Key the overlay table by the drawn trace's layer labels; unmatched keys are listed in the message |
| `patch_campaign_all_identical` | An activation-patching campaign fired at every site but EVERY fire replaced the site value with an identical tensor (clean == corrupted everywhere), so the published table is guaranteed to equal the corrupted baseline -- usually a facet anchored on an input-derived op rather than the computation it names | Inspect `tl.facets.facet_coverage(trace)` and re-anchor the facet before publishing the table as a null result |
| `check_no_accepted_steps` | The checks-kit death-spiral watchdog: N backwards since the last accepted optimizer step exceeded the threshold -- under a GradScaler this is the scale-collapse signature (every attempt skipped), the case where every retrospective method stays silent forever (checks memo D11) | Inspect the skip ledger (`report().ledgers['scale']`); check the loss for nonfinites and the scaler's `init_scale` |
| `frozen_param_changed` | A tensor declared frozen moved between accepted steps (warn-demoted form of the raise-class frozen check; exact clone evidence, every alias named) | Remove the tensor from the optimizer / set `requires_grad=False`, or drop the frozen declaration |
| `param_grad_nonfinite` | A live parameter gradient held NaN/Inf at the S-B pre-write site (warn-demoted form of the pre-write raise; weights were already written by the optimizer after the hook returned, so demotion trades protection for continuity) | Prefer the raise-class default; upstream `clip_grad_norm_(error_if_nonfinite=True)`; under fp16 use a GradScaler |
| `param_received_no_gradient` | A watched parameter received no gradient over a sustained M-of-N window of accepted steps (the D2 primary detector; single zero-grad steps are legitimate, hence the window; one emission per (check,site), re-armed only after a clean window) | Follow the finding's `follow_up` to `gradient_flow_audit`'s module/`is_frontier` column, which names the exact dead layer |
| `param_value_nonfinite` | A scheduled parameter-space scan found NaN/Inf in a parameter or buffer (warn-demoted form of the S-C raise; corrupt weights make every later step wasted compute) | Reload the last healthy checkpoint; forensics via `tl.debug.bisect_nan` on a captured trace |
| `update_ratio_out_of_band` | The raw update-to-weight ratio left the registration's explicit bounds over its window (no default band ships: a healthy model measured a 38x per-parameter spread) | Bounds are per-registration; compare raw and lr-normalized columns and the per-parameter history before acting |
| `observer_subscriber_failed` | An observability event-stream subscriber raised during publish; collection continues (subscriber isolation is the contract) and the subscriber will be disabled after consecutive failures reach the limit -- warned once per subscriber, never per event | Fix or unsubscribe the failing subscriber; subscriber bugs never interrupt collection |
| `observer_subscriber_disabled` | An observability event-stream subscriber was disabled after consecutive failures reached the limit; collection was never interrupted and every other subscriber keeps receiving events | Fix the subscriber and re-subscribe it; `EventStream.failure_counts()` carries the per-subscriber tallies |
| `lens_budget_band_missed` | The visible-detail budget resolver found no float-schedule point inside the two-sided band (and coverage floor when a channel is active); the nearest point is served with the dial disclosed by name (themes N10) | Focus the render with module= or vis_call_depth, or pass an explicit collapse= override |
| `lens_budget_above_ceiling_fallback` | Above the optimizer ceiling no call depth lands in the band; the nearest-depth estimate is served, disclosed as an estimate (themes N10 above-ceiling path) | Focus the render with module= or pass an explicit vis_call_depth= |
| `lens_secondary_degraded` | A lens SECONDARY member degraded (missing evidence or an unlicensed view); the render proceeds without it and carries the rendered notice -- silence is never an option (themes N2) | Re-capture or adjust the view to restore the member |
| `lens_nonfinite_not_checked` | The debug lens's nonfinite channel found ZERO checkable payloads: channel-level degrade -- one prominent legend line, no per-node motifs (themes N6 two-mode degrade) | Re-capture with saved payloads or CaptureOptions(track_nonfinite=True) |
| `layout_engine_stderr` | A Graphviz layout exited 0 but wrote to stderr -- above all the cairo "graph is too large ... scaling by N" clamp, the signal that raster pixel dimensions are fiction (vizmech D24; historically discarded on success) | Read `trace._last_render_geometry`; on a size clamp render direct SVG or reduce the graph with `module=` focus or `vis_call_depth` |
| `collapse_floor_fallback` | `collapse="auto"`/`"max"` could not build an optimized plan and fell back to the conservative floor plan -- possibly the entire uncollapsed graph (collapse memo D4: no silent floor; typed half on `OptimizerResult.planner`/`k_cap_exhausted`/`root_own_units`, plus a visible caption notice) | Reduce the rendered graph with `module=` focus, `vis_call_depth`, or rolled mode |
| `collapse_budget_fallback` | The (U, W) work estimator refused the quality planner admission (predicted cost over budget or U above the defensive constant); the render is the deterministic compact fallback plan, never an uncollapsed wall (collapse memo D5) | Reduce the rendered graph with `module=` focus, `vis_call_depth`, or rolled mode to re-admit the quality planner |
| `collapse_pathological_skip` | Trace crossed the pathological pre-gate (20x `COLLAPSE_OPTIMIZER_MAX_OPS` raw ops); smart collapse declines outright and the graph renders uncollapsed (collapse memo D5(i)) | Reduce the rendered graph with `module=` focus, `vis_call_depth`, or rolled mode |
| `collapse_watchdog_fallback` | The quality planner was abandoned mid-run (wall-clock watchdog or frontier allocation cap) and the deterministic fallback plan was served; every firing is an estimator bug, disclosed with (U, W, predicted, actual) (collapse memo D5(v)) | Report the disclosed tuple; reduce the rendered graph to re-admit the quality planner |
| `pattern_fold_refusals` | Pattern folding refused one or more matched instances on the honesty checks (external edge into the interior, protected junction, ambiguous continuation); counts and reasons disclosed per pattern (collapse memo D11) | Inspect the disclosed per-pattern counts; adjust the pattern or accept the refusals |
| `pattern_no_match` | A declared pattern matched zero sites in this trace (collapse memo D11) | Check the pattern path against the trace's op families and module classes |
| `pattern_token_unknown` | A pattern atom matched nothing in this trace; near-miss suggestions from the trace's vocabulary are included (collapse memo D11) | Use one of the suggested tokens or inspect `trace.ops` func names |
| `collapse_near_uncollapsed` | A `collapse="auto"`/`"max"` plan left >=90% of the rendered units visible -- nearly the uncollapsed graph presented as an optimized result (collapse memo D4 release invariant) | Reduce the rendered graph with `module=` focus, `vis_call_depth`, or rolled mode |
| `echo_zero_match` | A scoped `echo=` capture completed with zero narrated events: the selector matched nothing across the seen op events (a failed capture instead discloses "zero matches before failure" in the crash tail -- the crash may precede the scope) | Check the selector against trace labels, or use `echo=True` |
| `echo_sink_disabled` | Echo narration was disabled after an observer/sink instrumentation failure (warn once, disable the narrator, continue capture); when a model exception is active the secondary failure becomes a note -- the original exception always wins | Fix the sink or selector and re-run |
| `plugin_metadata_unreadable` | Plugin discovery could not inspect one installed distribution's dist-info metadata (a broken install); the entry-point group scan continued without it -- disclosed, never fatal, and discovery still never imports provider code | Repair or reinstall the broken distribution named in the message |
| `plugin_provider_load_failed` | Non-strict plugin activation skipped a broken provider and continued the batch; the failure is recorded in the activation ledger with state `failed` (strict mode raises `plugin_strict_load_failed` instead) | Fix or unpin the provider distribution; pass `strict=True` to raise on the first broken provider |
| `read_frozen_default_linearization` | `frozen=` was omitted on an attention-bearing model under a gradient-bearing method: the one-backward read's default MLP-output linearization deliberately changes transformer saliency numbers relative to Captum-family tools (M(reads) D5 mitigation; fires once per process) | Pass `frozen=` explicitly: `None` = total derivative (the Captum-familiar number); omitted/DEFAULT = published direct-edge linearization |
| `mean_over_self_alias` | `mean_fill(over='self')` is the legacy spelling of the explicit global-scalar mean; it maps to `over='all'` (F02, edits memo D17: the successor name requires a real `over=`, and the alias is disclosed for one migration window) | Spell `over='all'` directly |
| `sampling_agreement_class_singleton` | A stochastic donor draw resolved an agreement class of size 1: every draw returns the same donor, so the firing is deterministic -- a conditioned "resample" over a class of one is a fixed patch wearing a sampler's name (F02, edits memo D15; a reviewer must be able to SEE it) | Widen the agreement condition or add population members; `strict=True` refuses instead |
| `mi_grid_all_identical` | Every patching-grid cell produced an identical metric: a genuinely flat effect is a FINDING, so this discloses instead of refusing (mikit D21; refusals stay reserved for receipt failures -- no-fire, donor-identical campaigns) | Check the fire receipts and the metric before publishing a null result |
| `nongold_raw_value_read` | First raw value read (`Layer.out`/`Layer.tensor`) on a trace whose input values were synthesized (`input_size=` or inferred rung): the numbers are real measurements of a forward over RANDOM data, not of your data; fires once per trace object, and internal readers pass an ack so the warning always names a user read site (quickstart memo D7 -- the handoff case a passive persisted record cannot reach) | Re-capture with a real input for value-level claims, or filter the warning by its code to acknowledge |
| `netron_extent_budget_exceeded` | A netron export's root graph exceeds the ~27-rank extent budget where node labels stay legible at fit zoom (netron memo D-12): netron opens it, but as a rope, not a diagram | Export with `granularity="module"` (op/rolled projections), reduce `depth=` toward 1, or export a sub-module's trace |
| `netron_module_projection_fallback` | The netron module projection produced a function-call cycle, which kills netron outright (dead file, zero console errors); the export fell back to the valid op projection with `torchlens.granularity_fallback_reason` metadata (netron memo D-11) | Export with `granularity="op"`; per-call keying should make cycles impossible, so report the trace |
| `mfu_exceeds_one` | `tl.report.mfu` computed a utilization above 1.0 -- physically impossible, so a mode/peak/scope/timing input is wrong (costreport D16) | Verify each execution mode's advertised peak matches its real execution path (TF32/tensor-core recipes change peaks 2-16x) and that `step_seconds` covers the whole step |
| `metric_perturbation_out_of_range` | An infidelity perturbation produced values outside the observed input range (hull + 10% margin); the metric judges the perturbation as much as the attribution, so a domain-blind perturbation is disclosed rather than refused (valid ranges are rarely knowable, attrib memo D14) | Reduce noise_std or pass a domain-aware perturb callable |
| `text_bare_int_target_ambiguous` | A bare int text() target was read as a VOCAB id at the final non-padding position, but the int is also a valid position index for this input -- the one band where the two readings can collide (attrib memo D29); the resolution incl. the decoded token rides target_repr | Pass the explicit (position, vocab) tuple if a position was meant |
| `text_input_truncated` | text() truncated the tokenized input under an EXPLICIT max_length; the result records the original length and retained span and the scores cover the retained span only -- truncation is never silent (attrib memo D28) | Raise max_length to cover the full input |
| `text_residual_above_tolerance` | An EXPLICIT text() baseline spelling achieved a completeness residual above the 1% tolerance; explicit spellings stay available and ALL warn on a certificate shortfall (attrib memo D23) | Raise n_steps (or pass n_steps='auto'), or choose a task-appropriate baseline (baseline='auto') |
| `treescope_bridge_degraded` | The installed treescope cannot render torch tensors (the behavioral probe failed -- e.g. released 0.1.10 reads the removed `Tensor.names` on torch>=2.13), so bridged object cards render WITHOUT interactive array views; strict degradation names the reason in the render and warns once per process (F-A) | Upgrade treescope to a release containing the `Tensor.names` fix, or view tensors natively via the TorchLens card (`_repr_html_`) |
| `report_graph_fallback` | The offline HTML report could not embed the real Graphviz graph layout (renderer missing or every collapse rung over budget) and fell back to the labeled schematic canvas -- the picture is a grid, NOT the real graph geometry, and the report says so inline and in its manifest (F16, memo s6) | Install Graphviz, or reduce the graph with `vis_call_depth`/module focus and re-export |

Adding or renaming a warning code updates this table, the
`docs/reference/error_refusal_contract.md` code table (the package-wide
`code=` literal scanner reads that one), and the S-18 lockstep baseline in
the same change.
